## Independent calculations

The oracle integrates `-s * Gaussian * abs(det DH)` directly in the original
source-chord coordinate. It imports no production geometry helper or closed
first-moment formula. Independently mapped, whitened image-line cuts resolve
narrow endpoint peaks. It splits the source sign change, bounds omitted tails,
and applies all three resolution guards before 96/192-point integration.
All 3,886 independent order comparisons resolve. These floating calculations
and error guards are engineering evidence, not certified enclosures.

Twelve new scenes also use the unchanged independently implemented positive-area
conic helper. All 36 selected queries retain means at both integration orders
and four angular sides (`±h`, `±h/2`). Checks separately retain derivative-order
agreement, noncancelling area-order error amplified by `1/h`, step/half-step
agreement and the Richardson comparison. All pass their frozen criteria.
The check uses supplied Gaussian optics and synthetic geometry; it is not an
independent physical acquisition.

The sole unknown is `compressed-chart-e16-d0.0001`, pixel `(0,0)`. It attempts
the projective closed form and source-chord fallback, then reaches exactly
**4,096 panels**, with **154,388 evaluations** below the two-million evaluation
cap. Its derivative and error remain `None`. The independent orders give
`1591.5494281791937` and `1591.549428179194`, differing by
`2.2737367544323206e-13`, with 57 inspected panels and 9,332 evaluations.
No finite candidate value is reported for that query.

There is also an error-estimation limitation among resolved results. The largest
candidate/oracle difference is `1.7004538221954135e-8` at
`compressed-chart-e16-d1e-06`, whose candidate error estimate is approximately
`1.11e-11`. That difference passes the frozen relative comparison allowance
(`3.41554e-6`), but it exceeds both the estimate and the requested `1e-10`
absolute target. Agreement of oracle orders does not fix this underestimation.
A separate post-hoc calculation compares the supplied map's determinant using
exact rational arithmetic, 180-digit Decimal arithmetic and NumPy's LU-based
determinant. The latter's relative error is `4.98860e-11`; scaling the saved
oracle value by that error predicts `1.70319e-8` of the observed discrepancy,
leaving about `-2.73e-11`. This attributes the main error to the area normalizer,
without a new operator evaluation or repaired-run qualification. The current
estimate accounts for logarithm magnitudes rather than this determinant
conditioning. A stable determinant and revised error accounting remain needed.

The fallback allocates a fixed fraction of the requested allowance to every
possible leaf. That conservative allocation can require excessive subdivision
when a few panels carry most of a large derivative. Global adaptive error
allocation is a next hypothesis; it has not been implemented or validated in
this source. The requested tolerance, work cap and failed record remain intact.
