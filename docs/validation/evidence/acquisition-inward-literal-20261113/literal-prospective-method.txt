## Use the original actual training cost

For ordered training predictions `v`, observations `y` and positive weights
`w`, use the existing rounded-mode calculation:

```text
raw = y - v
r = w * raw
norm = hypot(*r)
cost = norm * norm
```

Weights multiply residuals; their squares therefore enter the quadratic
objective. The [hypot operation](https://docs.python.org/3.12/library/math.html#math.hypot)
computes the Euclidean norm; acceptance uses its operational binary64 square,
matching the existing fitter. It does not replace that value with an exact
rational sum. Do not divide by query count,
reweight observations or add reference/reserved penalties.

Refuse nonfinite predictions/residuals, nonpositive weights and nonzero raw
residuals that underflow to zero when weighted. Preserve the original norm
overflow and nonzero-square-underflow guards. Once the historical baseline
qualifies, acceptance is **strictly** `candidate_cost < baseline_cost`.
Equality is not an improvement; no tolerance changes that decision.

Compare the two complete source uint8 arrays and retain every changed
row-major source index. Record the selected source-62 target hit and every
collateral change separately from cost acceptance. A training-query index is
not a source-cell index. A code-pattern mismatch must not veto a strict actual
cost decrease; code preservation is a separate diagnostic.
