# Capture checklist

Object ID: __________  Revision: __________  Date: __________

## Define success

- [ ] Intended result: replica / replacement / decorative interpretation / mechanism.
- [ ] Critical interfaces and acceptance criteria listed.
- [ ] Required physical scale and target units recorded.
- [ ] Scale declaration states the reference dimension; one factor applies to every subject.
- [ ] Known, inferred, and unknown geometry separated.
- [ ] Original object condition and any damage documented.

## Prepare the evidence

- [ ] Original photographs retained without overwriting.
- [ ] Each image's provenance recorded: calibrated photo / ordinary photo / screenshot or crop / render / illustration or generated image.
- [ ] Duplicates and crops of the same frame identified; images of different physical objects kept in separate groups.
- [ ] Published labels recorded with what they refer to (envelope, cavity, window, contents) and their rounding interval.
- [ ] Terms for each third-party input recorded in the source manifest, with file hashes.
- [ ] Front/back/top/bottom/side and interpretive oblique views captured as needed.
- [ ] Scale reference placed in the appropriate plane and its placement photographed.
- [ ] At least two additional check lengths reserved from modeling.
- [ ] Camera/lens, focus/zoom choices, illumination, and preprocessing recorded.
- [ ] Blur, clipping, reflections, and missing coverage reviewed.
- [ ] Turntable background or masking strategy appropriate to the chosen software.
- [ ] Any surface treatment or markers documented.
- [ ] Separate underside pass has a planned alignment method.

## Reconstruct and inspect

- [ ] Registered views and camera arrangement look plausible.
- [ ] Raw reconstruction preserved.
- [ ] Scale and coordinate transforms saved.
- [ ] Reference-shape proportions checked before trusting a single-image rectification.
- [ ] Off-plane image measurements corrected for depth with a stated camera distance, or labelled as plane-scale guides.
- [ ] Derived values carry the weakest evidence class of their inputs.
- [ ] Missing observations distinguished from actual openings.
- [ ] Filled or inferred surfaces marked in the assumption register.
- [ ] Cleanup, smoothing, and decimation changes recorded.
- [ ] Independent lengths checked after scaling.
