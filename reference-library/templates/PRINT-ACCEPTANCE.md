## CAD handoff

- [ ] Native editable master included and regenerates.
- [ ] Governing values come from one parameter file; drawings, renders, and checks regenerate from it.
- [ ] Units, datums, and origin documented.
- [ ] Imported meshes converted explicitly for units and up axis, with extents checked.
- [ ] Exchange model opens independently.
- [ ] Critical dimensions have evidence and explicit acceptance criteria.
- [ ] Drawing views, sections, projection convention, and revision reviewed.
- [ ] Assumptions remain visibly labeled.

## Export and slicing

- [ ] Export dimensions match the CAD envelope.
- [ ] Closed-volume, orientation, intersection, and component checks appropriate to the model.
- [ ] Each printable part is one connected volume; no floating islands after Boolean operations.
- [ ] Minimum walls and features meet the chosen process's demonstrated limits.
- [ ] Thin walls, holes, supports, and small details inspected in layer preview.
- [ ] Hollow resin parts have drain and vent holes.
- [ ] Build-volume fit includes support/brim and exclusion areas.
- [ ] Keep-out volumes (insertion path, grasp, visibility) clear by the stated minimum distance, not merely non-intersecting.
- [ ] Assembly and tool access possible.
- [ ] Design clearance, process compensation, and finish allowance recorded separately.

## Physical validation

- [ ] Interface coupon printed using representative settings.
- [ ] Coupon tested in the finished state (primer, paint, or coating applied).
- [ ] Long guides or rails checked over their full engaged length.
- [ ] Measurements taken after relevant cooling/post-processing.
- [ ] Independent critical features inspected and results recorded.
- [ ] Assembly fit and intended motion tested where applicable.
- [ ] Fragile features survive normal handling and access; assembly is stable on its footprint.
- [ ] Load, wear, environmental, or start-up tests performed only if required and specified.
- [ ] Status stated as pass / fail / not tested, with no blank fields treated as passes.
