## A useful request for CAD assistance

“Use these photographs and this measurement table to reconstruct [object] for [purpose] at [scale], to be printed by [process and printer]. Mark unmeasured dimensions as assumptions and keep every governing value in one parameter file. Prioritize [interfaces] and keep [insertion path / grasp / visibility] volumes clear by [distance]. Produce an editable model, an exchange model, a dimensioned drawing, and a print-preparation checklist. Start with [coupon]. Report which dimensions and print behaviors are verified and which remain untested.”
