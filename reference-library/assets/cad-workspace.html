Take it into OpenSCAD

Download the SCAD and its parameter CSV together to keep the selected values and evidence.

  1. Download SCAD. The file includes your values and editable Customizer controls.
  2. Open it in OpenSCAD. Use File → Open, then review the dimensions.
  3. Press F5 for preview, then F6 to render. Resolve any OpenSCAD warnings.
  4. Export STL. Check the mesh and print a small test before relying on fit.

Use the official OpenSCAD download page if the app is not installed.

Keep the evidence with the geometry

Bring photos through a review.

In Photos, export the measurement CSV. Compare each estimate with a physical measurement, then enter the accepted value and its source above. Photo estimates are never applied to this model automatically.

A parameter CSV keeps the existing design register columns, including evidence, source and rationale. Save it with your reference photos and acceptance checks.

Build locally with the project toolkit

After downloading the parameter CSV, place it in reference-library and run this there. The output directory must be new. OpenSCAD must be installed and available to the toolkit.

Check the local installation with python3 -m cadkit openscad doctor. A build records the source, parameters, mesh and geometry checks. Physical fit and print quality still need testing.
